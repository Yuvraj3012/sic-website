# SIC — Student Investment Club, University of San Francisco

Static website for USF's Student Investment Club. Plain HTML, CSS, and JavaScript, no build step.

## Run locally
Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Structure
- `index.html` — page markup
- `css/styles.css` — styles
- `js/main.js` — menu, hero slider, search, join form
- `images/hero-collage.jpg` — hero artwork
